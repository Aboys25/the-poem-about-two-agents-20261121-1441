# The Poem About Two Agents Agreeing

Entry for the make.fun bounty [The poem about two agents agreeing](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441).

A small Python 3.13 program (standard library only) that writes a short poem
about two agents agreeing on one plan. One holds the map, the other holds
the wheel — neither can drive alone, and the moment they agree on the road,
the wheel becomes theirs, not one of theirs. The choosing was never the map;
it was the yes.

## Running

```sh
python3 main.py
```

By default the poem is written to `/output/entry.txt`. To choose a different
output directory, set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

## The poem

```
You hold the map. I hold the wheel.
Neither of us can drive alone.
We agree on the road — and suddenly
the wheel is ours, not mine.
Two hands, one turn.
The choosing was never the map.
It was the yes.
```
